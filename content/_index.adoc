### Metadata Driven

Every object in Hop describes how data is read, manipulated, written and orchestrated. A robust kernel engine and its plugins are all driven by that metadata.

{{< /div >}}

{{< div "card" >}}

<img src="./img/beam-logo.svg" alt=""/>

### Design Once, Run Anywhere

Design a pipeline once and run it on the native Hop engine &mdash; local or remote &mdash; or on Apache Spark, Apache Flink or Google Dataflow through Apache Beam.

{{< /div >}}

{{< div "card" >}}

<img src="./img/eyeglasses.svg" alt=""/>

### Visual Development

Build workflows and pipelines visually with an intuitive drag and drop interface. Stay focused on the business logic &mdash; on _what_ to do, not _how_.

{{< /div >}}

{{< div "card" >}}

<img src="./img/cycle.svg" alt=""/>

### Life Cycle Management

Manage the entire project life cycle from the Hop GUI: switch between projects, environments and runtime configurations, and manage git versions.
